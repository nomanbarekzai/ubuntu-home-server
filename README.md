# Ubuntu Home Server: Setup, Security & Monitoring

## Overview
I turned an Ubuntu laptop into a small home server and managed it
remotely from another computer, practicing tasks data center and
IT support technicians do every day.

## Skills practiced
- Remote administration with SSH
- Firewall configuration (ufw)
- User management
- Automated backups with cron
- System monitoring with Netdata

## What I did

### 1. Remote access (SSH)
Installed OpenSSH server and connected from a second laptop.
![SSH login](screenshots/01-ssh-login.png)

### 2. Firewall and users
Enabled ufw, allowed only SSH, and created a separate user account.
![Firewall](screenshots/02-firewall.png)

### 3. Automated backup
Scheduled a daily backup of a folder using cron.
![Backup](screenshots/03-backup-cron.png)

### 4. Monitoring
Installed Netdata to watch CPU, memory, disk and temperature.
![Netdata](screenshots/04-netdata.png)
